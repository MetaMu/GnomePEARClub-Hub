# Gnome Pear Club Hub

The official Gnome Pear Club member hub: Realmfinder, pear-credit tasks, the 2026 class portrait, the 23-member roll call, and the eight-realm directory.

## Included

- 14-question Realmfinder with local result history
- Eight realm directory
- Twenty-three member spotlight carousel
- Official class portrait section
- Local profile starter page
- Device-local pear-credit ledger
- Responsive woodland-inspired visual system

## Run it

This is a static site. Open `index.html` directly, or serve the repository with any static host such as GitHub Pages, Netlify, or Vercel.
